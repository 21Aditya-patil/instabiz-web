# 🚀 Instabiz Web

A modern and fully responsive SaaS / AI agency website built using **React.js**, **Tailwind CSS**, and **Framer Motion**.

Designed with a premium UI/UX approach featuring:
- Smooth animations
- Glassmorphism effects
- Modern gradients
- Fully responsive layouts
- Interactive portfolio tabs
- Startup-style landing page sections

---

## ✨ Features

- ⚡ Modern SaaS Landing Page
- 🎨 Premium UI/UX Design
- 📱 Fully Responsive Design
- ✨ Smooth Framer Motion Animations
- 🧊 Glassmorphism Components
- 🗂 Dynamic Portfolio Tabs
- 🧠 Modern Tech Stack Showcase
- 🌐 Multi-section Single Page Website
- 📌 Sticky Responsive Navbar
- 🎯 Optimized for Performance

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Framer Motion
- React Icons

### Styling & Animation
- Tailwind CSS
- Framer Motion
- CSS Variables
- Glassmorphism UI
